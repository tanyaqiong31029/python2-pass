# 官方模拟卷材料（27A）

- **来源**：上海市教育考试院"上海市高等学校信息技术水平考试"官方网站公开下载页
  https://scite.shmeea.edu.cn/home/TestPaper （Python 程序设计及应用（二三级），科目代码 27）
- **文件**：`27A.pdf`（模拟试卷）、`27A.zip`（官网提供的素材包，内容与 PDF 相同）
- **用途**：本仓库将其转换为可在线判题的题库（`data_src/official27A.json`，题目 id 以 `p27-` 开头），供考生备考练习；页面与模拟考中均已标注来源。
- **再分发说明**：该材料为考试院面向考生公开发布的备考资料，本仓库按原始出处完整保留并注明来源，未作内容删改；如权利方提出异议，将立即移除。
- **题库改编**：`data_src/official27A.json` 中的参考答案、数据文件（平均气温.txt、huaqiang.html、classroom.db 等）与 LossRatio 等价模块为本站作者为实现在线判题所编写/复刻，非官方材料本身。
